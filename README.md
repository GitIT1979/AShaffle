# AShuffle

Одностраничное приложение (один HTML-файл): возвращает трекам их истинные имена и перемешивает их так, чтобы рядом не оказывались песни одного исполнителя.

Версия: **v11.11**

## Быстрый старт

Открывать нужно **через локальный сервер**, а не двойным кликом: со страницы `file://` браузер режет запросы к Deezer, iTunes и MusicBrainz, и проверка названий молча ничего не находит.

```
cd D:\AI_projects\AShaffle
python -m http.server 8123
```

Затем открыть <http://127.0.0.1:8123/AShaffle.html>.

## Два шага

1. **🪄 Make this true!** — проверяет каждое название в интернете, показывает результат в исходном порядке и без нумерации. Отсюда можно скачать как отдельные файлы, так и всю папку (или ZIP).
2. **OK** — рабочий список и кнопки скрываются, остаётся список исправленных имён. Ниже — «Скачать все в папку» и **🎲 Ashuffle this!**: перемешивание с нумерацией `001…`.

Проигрывание: кнопка ▶ в строке рабочего списка (одновременно играет только один трек).

## Как ищутся имена

1. **Теги важнее имени файла.** Читаются ID3v2 (mp3), VORBIS_COMMENT (flac), `ilst` (m4a/alac), Ogg Vorbis/Opus, APEv2 (ape), ASF (wma). Тег перекрывает разбор имени.
2. **Длительность** берётся из метаданных `<audio>` (запасной путь — `TLEN` в mp3, `STREAMINFO` во flac). Кандидат отбрасывается, если расходится больше чем на **±10 с**.
3. **Источники:** Deezer (через JSONP — у них нет CORS), iTunes, MusicBrainz, Discogs (перекрёстная проверка для совпадений ниже 80%).
4. **Порядок запросов.** Для кириллицы: Deezer → iTunes → MusicBrainz, потому что MB почти не знает русскую поп-музыку. Для латиницы: MusicBrainz (точная пара) → общая строка → транслит → Deezer → iTunes. В конце — короткие запросы на случай обрезанного имени.
5. **Выбор кандидата** — не первый подходящий, а лучший по оценке: покрытие слов запроса, число лишних слов, близость длительности.
6. **Сравнение нечёткое:** расстояние Левенштейна ≤1–2 и совпадение по префиксу, поэтому «направл» совпадает с «направление», «Мишел» с «Мишель».
7. **Транслитерация в обе стороны** и небольшой словарь переводов имён групп (`technology → Технология`).
8. **Защита от подмены.** Если исполнитель в файле известен, результат обязан с ним совпадать. Исключения: перевёрнутые кредиты (артист и название в базе зеркальны) и случай, когда найденный исполнитель — часть исходного («Sean Paul» внутри «Imanbek & Sean Paul»).
9. **Если ничего не нашлось** — имя остаётся как было, в строке появляется «✎ исправить».
10. **Обратный разбор.** Для имён из трёх и более частей через дефис, если обычный разбор не дал результата, имя читается с конца: последняя часть — исполнитель. Такой результат помечается значком **↔**.

## Чистка имён

Срезается:

- номера треков и длинные числовые префиксы;
- мусорные префиксы: `TVВиктор`, `UYTДжанго`, `KR`, `AQF`, `nai`, `ney`, `11111`;
- языковые хвосты (`-eng`, `-rus`);
- сайты-водяные знаки: `(Sefon.me)`, `(Sefon.Pro)`, `[mp3uk.net]`, `sonq.ru`, `muzter.net`, `vmuzone.com`;
- шум в скобках: `(Official Video)`, `(Lyrics)`, `(HD)`, `(Remastered 2011)`, `(Deluxe Edition)`, `(Bonus)`, `(Explicit)`, `(feat. …)`, `(prod. …)`, годы, битрейт, `(OST)`, `(Single)`, хвосты `- Topic`.

Сохраняется:

- варианты записи: `(Live)`, `(Remix)`, `(Acoustic)`, `(Instrumental)`, `(Demo)`, `(Radio Edit)` — это разные записи;
- найденное название пишется **как есть**, если база вернула его с уточнением;
- регистр и `ё` из файла сохраняются, если различие только в них; но если в файле всё строчными (`kesha`), берётся написание базы.


## Ограничения

- **Распознавания по звуку нет** — это направление сознательно отклонено; идентификация идёт по тегам, имени и длительности.
- **MusicBrainz** почти не содержит русскую поп-музыку, поэтому основной источник для неё — Deezer и Apple.
- **Словарь переводов имён** небольшой; редкие случаи вроде `Dzhango-EGuseva` требуют ручной правки.
- **Длительность ±10 с** может не спасти от кавера с той же длиной; для файлов без исполнителя это главный источник ошибок.
- **ZIP** собирается в памяти и не поддерживает ZIP64: архив больше 4 ГБ или свыше 65 535 файлов — понятная ошибка, а не битый файл.
- **Файлы без тегов и с бессмысленным именем** (`topremix_net__9162354`) не распознаются — угадывать нечем.
